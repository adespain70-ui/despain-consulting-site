<section class="advance-intro">
  <div class="container">
    <p class="advance-quote">"So you set up a GitHub. Now what?"</p>
    <p>GitHub is where your project lives online. Connecting it to Claude means Claude can <strong>read the code in that project</strong>, so you can ask about it and get real help. It works on <strong>every plan, including the free one</strong>. You need a GitHub account and your project saved there. That is it.</p>
  </div>
</section>

<section class="advance-framework">
  <div class="container">

    <div class="advance-step">
      <div class="advance-letter">1</div>
      <div class="advance-step-content">
        <h2>Open a new chat and click the plus</h2>
        <p>In a Claude chat, find the <strong>plus button</strong> near the message box and choose <strong>Add from GitHub</strong>.</p>
      </div>
    </div>

    <div class="advance-step">
      <div class="advance-letter">2</div>
      <div class="advance-step-content">
        <h2>Approve access, once</h2>
        <p>The first time, Claude asks you to <strong>sign in to GitHub and give permission</strong>. If your project is private, you approve access once and you are set. This is a one-time step.</p>
      </div>
    </div>

    <div class="advance-step">
      <div class="advance-letter">3</div>
      <div class="advance-step-content">
        <h2>Pick your repository and files</h2>
        <p>Choose the project you saved (your <strong>repository</strong>), then the files you want or the whole thing. That is it, Claude can now see your code. Use the <strong>Sync</strong> icon anytime to pull in your latest changes.</p>
      </div>
    </div>

  </div>
</section>

<section class="advance-intro">
  <div class="container">
    <h2>Two ways to do it</h2>
    <p><strong>In a chat</strong> is best for a one-off question. Click the plus, add from GitHub, ask.</p>
    <p><strong>In a Project</strong> keeps it connected across chats. Add GitHub to the project's knowledge, which is great for something you work on often.</p>
  </div>
</section>

<section class="advance-intro">
  <div class="container">
    <h2>What this does, and what it does not</h2>
    <p>Once connected, you can ask Claude to explain your project, help you fix a bug, or walk you through code you did not write, all from your real files.</p>
    <p class="advance-quote">This connector lets Claude read and work with your code. If you want Claude to write changes and push them back to GitHub, that is a different tool called Claude Code. This is the simple first step.</p>
  </div>
</section>

<section class="advance-framework">
  <div class="container">
    <div class="advance-step">
      <div class="advance-letter">?</div>
      <div class="advance-step-content">
        <h2>If something looks off</h2>
        <p><strong>Do not see your repository?</strong> Re-run the GitHub authorization and make sure the repo you want is included.</p>
        <p><strong>Claude talking about old code?</strong> Click the Sync icon to pull your latest changes.</p>
        <p><strong>On the free plan?</strong> No need to worry. The connector works on free, Pro, and everything above.</p>
      </div>
    </div>
