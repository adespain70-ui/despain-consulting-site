# Default Visual System

Use `references/despain-visual-brief.md` and `assets/despain-logo.png` for the
default DeSpain Consulting edition: a warm, light, editorial one-pager in the
brand palette (warm brown `#877167`, cream `#FCF7F1`, taupe `#A59E97`) with
Playfair Display titles and Inter body text.

If the user names another brand, template, or neutral treatment, use it for
that run. Do not change this pointer unless the user explicitly asks to make a
new default.

The original AIBL student edition is kept for reference at
`references/aibl-dark-visual-brief.md` with `assets/aibl-logo.png`.
